The base module has the building blocks that most Cyberismo modules use: pages, tasks, controlled documents with an approval workflow, decisions, meeting memos, role assignments, checklists, and dashboard widgets. It also has card types and templates for documentation: predicates and external functions of logic programs, and the documentation of a module.

Other modules build on base. The ISMS essentials module and the secure development essentials module use it, so most projects get base as a dependency of one of them.
