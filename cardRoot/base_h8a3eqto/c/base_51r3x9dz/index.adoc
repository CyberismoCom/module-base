The child cards of this page are test fixtures for the checklist pattern: the checklist item card type, the `base/reports/checklist` report, and the shared predicates in `base/calculations/checklist`.

Each child card is a checklist. Its content tells the expected result. The checklist named "Checklist" is an instance of the `base/templates/checklist` template.

The executable assertions are in `tests/checklist.lp` in the module repository. To run them, go to the project root and run:

----
cyberismo calc run tests/checklist.lp
----

The tests pass when the "results" array is empty. Each result is one failed assertion.

Do not change the titles of the child cards or the identifiers of the checklist items. The tests use them to find the fixtures.
