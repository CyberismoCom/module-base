= Progress tiles widget

Each tile fills up from the bottom with its value. By default, 100 is green, a value between 0 and 100 is yellow, and 0 has no fill. A tile without a value is empty and shows "-" or its text. A tile with a card key opens that card in the app.

== Phases of a project, with links

The tiles open the other widget test pages.

{{#report}}
  "name": "base/reports/progressTilesWidget",
  "title": "IoT device: 28% of level 1",
  "legend": "Click a tile to open it",
  "tiles": [
    {"label": "Foundation", "value": 100, "cardKey": "base_e0e1hvzl"},

== Colours set by hand, and edge values

The fill is half transparent, so the text has the normal text colour at every value. Check that the text is easy to read on each colour, in the light and the dark theme.

{{#report}}
  "name": "base/reports/progressTilesWidget",
  "title": "Colours",
  "tiles": [
    {"label": "Blue", "value": 60, "colour": "blue"},
    {"label": "Red", "value": 100, "colour": "red"},
    {"label": "Orange", "value": 54, "colour": "orange"},
    {"label": "Purple", "value": 1, "colour": "purple"},
    {"label": "Yellow", "value": 55},
    {"label": "Text \"quoted\"", "value": 100, "text": "Done"}
  ]
{{/report}}

== Eight tiles with long labels

The tiles get narrower so that the row fits the content column of the app at 1280 pixels. A long label breaks into two lines and gets smaller when it does not fit.
