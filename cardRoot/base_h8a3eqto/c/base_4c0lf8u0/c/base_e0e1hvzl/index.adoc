== Many categories, long names

Where `pieWidget` would fall back to a table, a bar chart still reads. Bar length carries
the magnitude, so one hue is enough and there is no six-category ceiling.

{{#report}}
  "name": "base/reports/barWidget",
  "title": "Findings by control family",
  "legend": "open findings only",
  "bars": [
      {"label": "Access control", "value": 31},
