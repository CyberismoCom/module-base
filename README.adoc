== Install

To use the base module in your Cyberismo project, go to the project folder and run:

    cyberismo module install https://github.com/CyberismoCom/module-base.git

Most projects get the base module as a dependency of another module, for example the ISMS essentials module or the secure development essentials module.

The documentation of the base module is in the card root of this repository, under the card "Base". Open this repository as a project in the Cyberismo app to read it. For more about Cyberismo, see the https://docs.cyberismo.com[Cyberismo documentation].
