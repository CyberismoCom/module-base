The child cards of this page are test fixtures for the task calculation (`base/calculations/task`) and the adoption steps (`base/calculations/adoptionStep`). Each card tells its expected result.

The executable assertions are in `tests/tasks.lp` in the module repository. To run them, go to the project root and run:

----
cyberismo calc run tests/tasks.lp
----

The tests pass when the "results" array is empty. Each result is one failed assertion.

The fixtures use fixed dates far in the past or the future, so that the results do not change over time. Do not change the identifiers of the fixtures. The tests use them to find the fixtures.
