The child cards of this page are test fixtures for document control (`base/calculations/documentControl`): controlled documents and their review tasks. Each document tells its expected result.

The executable assertions are in `tests/document-control.lp` in the module repository. To run them, go to the project root and run:

----
cyberismo calc run tests/document-control.lp
----

The tests pass when the "results" array is empty. Each result is one failed assertion.

The fixtures use fixed dates and a review period of 36500 days, so that the results do not change over time. Do not change the identifiers of the fixtures. The tests use them to find the fixtures.
